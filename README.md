# DMS Notifier - نظام إشعارات المستندات

تطبيق سطحي (Desktop Application) مُصمم للعمل في الخلفية على بيئة Windows لتنبيه المستخدمين بالمستندات والمعاملات الجديدة والمهام المتأخرة من نظام إدارة المستندات (DMS).

---

## 🌟 المميزات الرئيسية

- **إشعارات لحظية وفي الخلفية**: يعمل البرنامج في صينية النظام (System Tray) ويُصدر تنبيهات عند وجود مستندات جديدة.
- **التشغيل التلقائي**: إمكانية تفعيل التشغيل مع بداية تشغيل نظام Windows عبر التعديل على السجل (Windows Registry).
- **أمان وتشفير**: تشفير بيانات الاتصال بقاعدة البيانات محلياً باستعمال خوارزميات **AES-CBC** ومفتاح مفاجئ **PBKDF2**.
- **دعم العمل المقطوع (Offline & Caching)**: تخزين محلي كامل للإشعارات والإعدادات عبر قاعدة بيانات **SQLite** خفيفة وسريعة.
- **واجهة مستخدم تفاعلية (PyQt5)**:
  - عرض آخر الإشعارات الواصلة للمستخدم.
  - جدول مدمج لعرض جميع الإشعارات مع خيارات الفلترة المتقدمة (حسب التاريخ، الموضوع، أو الجهة المرسلة).
  - دعم النسخ المتعدد للخلايا وسجلات البيانات بسهولة.
  - إعدادات مرنة للاتصال بقاعدة البيانات واستيرادها من ملفات نصية مشفرة.

---

## 🛠️ التقنيات المستخدمة

- **اللغة الأساسية**: Python 3.x
- **واجهة المستخدم (GUI)**: PyQt5
- **قواعد البيانات**:
  - **SQL Server**: اتصال رئيسي عبر `pymssql` لجلب البيانات المعاملات والمسندات.
  - **SQLite3**: قاعدة بيانات محلية لتخزين الجلسات، التنبيهات، والسجل المحلي.
- **التشغيل والحزم**: PyInstaller (لتحويل المشروع إلى ملف `.exe` مستقل).
- **الأمان**: `PyCryptodome` (خوارزمية AES وتطوير المفاتيح عبر PBKDF2).

## ⚙️ متطلبات التشغيل والتثبيت

### 1. المتطلبات الأساسية
- نظام تشغيل **Windows 10 / 11** أو **Windows Server**.
- بيئة **Python 3.8+** (في حال التشغيل من السورس كود).

### 2. تثبيت المكتبات (Dependencies)

افتح موجه الأوامر (Terminal / CMD) في مجلد المشروع وقم بتنفيذ:

```bash
pip install -r requirements.txt
```

محتويات ملف `requirements.txt`:
- `pyodbc >= 4.0.39`
- `PyQt5 >= 5.15.9`
- `mssql-python`
- بالإضافة إلى مكتبة `pycryptodome` للتشفير.

## 📦 بناء وتجميع التطبيق إلى EXE

لتحويل المشروع إلى ملف تنفيذي يعمل بشكل مستقل بدون الحاجة لتثبيت Python على أجهزة المستخدمين:

1. أضف أيقونة البرنامج باسم `icon.ico` في المجلد الرئيسي.
2. قم بتنفيذ الأمر التالي عبر **PyInstaller**:

```bash
pyinstaller test.spec
```

سيتولد ملف `DMSNotifier.exe` داخل مجلد `dist/`.

## 🔐 نظام التشفير والأمان

يقوم التطبيق بتشفير نصوص الاتصال (Connection Strings) بقاعدة بيانات SQL Server قبل حفظها في قاعدة البيانات المحلية SQLite (`dms_notifier.db`):
- **الخوارزمية**: AES mode CBC.
- **اشتقاق المفتاح**: PBKDF2 مع SHA1.
- **ملفات الاتصال المشفرة**: يتيح التطبيق إمكانية استيراد إعدادات الاتصال مباشرة من ملفات نصية مشفرة سهلة التوزيع بين المستخدمين.
